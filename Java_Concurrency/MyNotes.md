# Notes

One CPU can run multiple programs or processes at, almost, the same time by switching between executing one for a little time and then switch to the next. This happens so fast that it seems like a "same time" execution.


-> Multithreading is different from multitasking


### Thread context:
**Thread's context** is the complete state needed to `pause` a thread and, later, `resume` it exactly where it left off.
